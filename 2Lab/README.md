Расстановка наблюдательных пунктов на графе для максимального покрытия при ограниченном числе пунктов.

## Постановка

Граф неориентированный, связный, содержит 40 вершин и 80 рёбер. Разрешены не более 5 пунктов. Пункт покрывает собственную вершину и всех непосредственных соседей. Цель — число различных покрытых вершин. Повторное покрытие не суммируется. Минимальный масштаб задания (20 вершин) соблюдён.

Внутри JSON и программы вершины индексируются от 0 до 39; в результатах для человека — от 1 до 40. Генотип представляет собой бинарную строку длины 40, хранящуюся как целая битовая маска.

## Генерация данных

Создаётся цикл на 40 вершинах. Из упорядоченного списка неиспользованных пар `i < j` генератор `random.Random(260514)` выбирает 40 дополнительных рёбер без возвращения. Граф содержит 80 рёбер, без петель и повторов, и связан благодаря исходному циклу. Приложенный граф используется непосредственно, без скачивания внешних данных.

## Алгоритмы и бюджет

Проводятся четыре серии по 20 seed: 42–61. Каждая использует **ровно 8000 вычислений покрытия**.

| Метод | Ограничения | Мутация |
|---|---|---|
| `penalty_bit` | Штраф 41 за каждый пункт сверх пяти | Инверсия каждого бита с вероятностью 0,025 |
| `repair_bit` | Случайное удаление лишних пунктов | Та же битовая мутация |
| `repair_swap` | Тот же ремонт | Обмен выбранного места на свободное с вероятностью 0,9; при числе пунктов меньше пяти — добавление |
| `random_feasible` | Генерация пятиэлементного набора | Независимые равномерные наборы |

Для ГА: популяция 80, турнир 3, равномерный кроссовер 0,9, элитизм 2. Первая начальная особь — пустой набор; остальные имеют вероятность единичного бита 0,125. В вариантах с ремонтом он применяется при инициализации, после кроссовера и после мутации. Элитные оценки повторно не вычисляются. Все новые кандидаты, включая повторяющиеся, оцениваются. Последнее поколение может быть неполным. Остановка по стагнации отсутствует.

Сравнение `penalty_bit` с `repair_bit` меняет только обработку ограничения. Сравнение `repair_bit` с `repair_swap` меняет оператор мутации при неизменных остальных настройках. Вероятности двух мутаций относятся к разным единицам (бит и особь), поэтому не являются одинаковой интенсивностью разрушения генотипа.

Ремонт удаляет случайные лишние места, не вызывая целевую функцию. Обмен сохраняет допустимость. Штраф превышает любое возможное покрытие, поэтому все недопустимые решения имеют отрицательную оценку, а допустимые — неотрицательную. Итоговый архив хранит только допустимые решения.

Жадная эвристика требует 190 оценок и является дополнительным ориентиром. Честное сравнение с одинаковым бюджетом выполняется со случайным допустимым поиском. Полный перебор всех 658 008 пятиэлементных наборов используется только для проверки максимума. ГА не получает ни оптимальный набор, ни жадный набор, ни значение максимума во время поиска.
