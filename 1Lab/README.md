## Состав сдаваемых материалов

- `Lab1.ipynb` — самостоятельная реализация генетического алгоритма, обязательные эксперименты и построение графиков.
- `config.json` — все основные параметры эксперимента и seed.
- `requirements.txt` — список зависимостей для локального запуска.
- `results.csv` — результаты 20 независимых запусков в машиночитаемом виде.
- `summary.csv` — итоговая статистика: лучшее, среднее, медиана, стандартное отклонение и худшее значение.
- `convergence.png` — график сходимости базового ГА по 20 запускам.
- `parameter_comparison.png` — сравнение двух конфигураций, отличающихся только масштабом мутации.
- `Отчет.pdf` — итоговый отчёт.

## Параметры

Базовая конфигурация: размер популяции 50, 100 состояний популяции (начальное + 99 новых), бюджет 5000 вычислений целевой функции, турнирная селекция `k=3`, арифметический кроссовер `p_c=0.8`, гауссовская мутация `p_m=0.2`, `sigma=0.5`, clipping в `[-5, 5]`, элитизм 1 особь. Для сравнения конфигураций меняется только `sigma`: `0.5` против `0.2`. Используются 20 seed: 42–61.

## Запуск в Google Colab

1. Загрузить в Colab файлы `Lab1_Zarechkin_v14_final.ipynb` и `config.json` в одну рабочую папку.
2. Открыть notebook и выполнить **Среда выполнения → Выполнить все**.
3. Notebook автоматически проведёт 20 запусков базового ГА, 20 запусков альтернативной конфигурации и 20 запусков Random Search при одинаковом бюджете 5000 вычислений функции.
4. В рабочей папке будут созданы/обновлены `results.csv`, `summary.csv`, `convergence.png` и `parameter_comparison.png`.

## Локальный запуск

Требуется Python 3.10+ и пакеты `numpy`, `pandas`, `matplotlib`, `jupyter`.

Пример:

```bash
python -m pip install -r requirements.txt
jupyter notebook Lab1_Zarechkin_v14_final.ipynb
```

После открытия notebook выполнить **Run All**.

## Воспроизводимость

В каждом запуске используется отдельный фиксированный seed из диапазона 42–61. При одинаковой версии библиотек и тех же параметрах результаты воспроизводимы. Ключевые эволюционные операторы реализованы в notebook самостоятельно; готовые оптимизаторы не используются.
